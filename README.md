# Sorting Algorithm Comparison

## Project Description
This is a C programming project where I used Merge Sort and Quick Sort to sort an array. It also compares the number of comparisons made by both sorting algorithms.

After sorting the original array, the program merges it with another sorted array and displays the final updated array.

## Features
- Take input from the user.
- Sort the array using Merge Sort.
- Sort the same array using Quick Sort.
- Count comparisons of both algorithms.
- Merge two sorted arrays.
- Display the final updated array.

## Algorithms Used
1. **Merge Sort:** Divides the array into smaller parts, sorts them, and combines them.
2. **Quick Sort:** Uses a pivot to divide the array and sort it.
3. **Merge Operation:** Combines two sorted arrays into one sorted array.

- C
